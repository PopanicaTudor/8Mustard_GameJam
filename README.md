# 🧟 1HP: Nex Ferre  
**Amazon Games Game Jam Submission**

---

## 🏆 Project Overview

**1HP: Nex Ferre** is a short, story-driven 2D survival game built in just **48 hours** during an **Amazon Games Game Jam**.  

The player steps into the shoes of **Nex Ferre**, a survivor navigating a brutal zombie apocalypse. With only **1 Hit Point (1HP)**, every encounter could be your last — forcing you to think strategically, choose your battles wisely, and uncover the dark truth behind the outbreak.

---

## ✨ Key Features

- 🕹️ **Game Jam Build** – Fully designed, developed, and submitted in just **48 hours**.  
- 📖 **Story-Driven Narrative** – A focused, impactful story following Nex Ferre’s desperate search for answers.  
- ⚔️ **Dual Gameplay Mechanics** – Combine **stealth** and **combat** to survive against overwhelming odds.  
- 🔄 **Procedural Generation** – One level is procedurally generated, ensuring a **unique layout** and **fresh experience** with each run.  
- 🥚 **Secret True Ending** – Discover all **hidden Easter Eggs** to unlock a **special “Good Ending.”**  
- 🧱 **OOP Architecture** – Clean, maintainable, and scalable codebase built with **Object-Oriented Programming** principles.
